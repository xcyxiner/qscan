核心技术栈：Qt + C++ + VTK/OpenGL + 多线程 + 串口 / 网络通信
功能模块：
设备通信层：用 Qt 的串口 / Network 模块，模拟 X 光设备数据采集（可以写一个模拟下位机发数据的程序，或者用随机数生成模拟数据）
数据处理层：多线程处理图像数据（用 Qt 的 QThread/QtConcurrent），模拟安检设备的图像预处理（灰度调整、对比度增强，甚至加个简单的边缘检测）
可视化层（加分项核心）：
用VTK实现 2D/3D 图像渲染（比如加载 DICOM 格式的医学影像切片，或者模拟安检设备的点云 / 断层扫描数据）
用OpenGL写一个简单的渲染模块，实现图像缩放、平移、伪彩色映射（比如金属物品高亮显示）
UI 交互层：Qt 实现控制面板，比如参数调整（亮度 / 对比度）、设备连接状态显示、数据日志记录

## 当前实现落点

第一阶段已经按“完整演示闭环优先”的方向落下基础工程结构，当前实现重点包括：

- 使用 CMake 组织 Qt 桌面应用与测试目标
- 使用模拟扫描器持续产生扫描帧
- 使用独立处理链路执行亮度、对比度和可选锐化增强
- 使用 Qt Widgets 构建主窗口、扫描视图、控制面板、状态面板和日志面板
- 使用 Qt Test 为控制器、模拟扫描器、图像处理器和应用状态流补充基础测试

## 构建要求

- 工程当前要求 Qt6，不再回退到 Qt5
- 使用 MinGW kit 时，必须搭配同一套 ABI 的 MinGW 版 Qt6
- 不要让 CMake 解析到 Conda/Anaconda 的 Qt `.lib`，否则会在链接阶段出现大量 Qt 符号未定义
- 如果本机装有多个 Qt，优先在 Qt Creator 里选择 Qt 6 MinGW kit，或显式设置 CMAKE_PREFIX_PATH / Qt6_DIR
